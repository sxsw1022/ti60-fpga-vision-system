# Ti60 FPGA 实时视觉系统源码包

本包以 `2026-10-16/edge_comparison/I_fine_stroke_canny` 独立工程为基线，打包时未修改原工程源码。顶层工程文件是 `Ti60_Demo.xml`，目标器件 Ti60F225，工程记录的软件版本为 Efinity 2026.1.132。

## 目录

- `src/`：视频采集、图像处理、按键、OSD、DDR 与 HDMI 的 RTL。
- `ip/`：工程依赖的 IP 源文件和配置；为保证工程可打开，整目录保留。
- `sim/`：仿真源文件、特征/图像测试输入；已排除生成的 `.vvp` 和旧日志。
- `tools/`：仿真回归脚本、形状矢量生成与数字模型训练脚本。
- `optdigits_data/`：数字分类训练所需的原工程数据文件。
- `outflow/Ti60_Demo.bit`：随包提供的 I 版下载文件，不属于源码。
- `reports/`：该版资源和时序报告。
- `docs/`：原工程说明及 I 版变更说明。原 `README.md` 中部分“当前版本”文字是历史记录；请以本文件和 `docs/I版细字保护说明_20261021.md` 为准。

## 使用

1. 解压整个文件夹，保持目录结构。
2. 在 Efinity 2026.1 系列打开根目录的 `Ti60_Demo.xml`，核对器件、引脚和时钟约束后再综合或下载。
3. `src/`、`ip/` 和根目录的 XML/SDC 是工程依赖文件，不能只拷贝 `example_top.v`。
4. `outflow/Ti60_Demo.bit` 是原工程已有的编译输出。实际板卡演示仍应确认硬件版本及现场接线一致。

## 打包范围

保留所有当前工程源码、工程配置、测试源和训练数据；排除 `ooc/`、`work_syn/`、`work_pnr/` 及 `outflow/` 中除 bitstream 之外的自动生成文件。各文件 SHA-256 见 `文件校验清单.csv`。
